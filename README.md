# Eclipse Orbit Releases

This repository hosts the official downloadable Eclipse Orbit desktop releases.

Release assets are published automatically by the **Build and Publish Release** workflow in [the Eclipse Orbit source repository](https://github.com/LinkZelda99-cpp/Eclipse-Orbit). Each release includes Windows, macOS, and Linux packages plus SHA-256 checksums.

The in-app updater reads the latest stable release from this repository. Pre-releases are published for testing and are intentionally excluded from automatic stable update checks.

Do not upload source code or credentials here. The source code and build workflow live in the main Eclipse Orbit repository.
